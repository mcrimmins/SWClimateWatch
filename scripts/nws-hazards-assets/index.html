How to read these maps and coverage

This retrospective view uses IEM's archive of NWS VTEC-enabled hazards, with no hazard-type whitelist. Statements and outlooks appear only if present in this archive. Special Weather Statements, non-VTEC products, routine forecasts and discussions are not comprehensively included.

Intervals are half-open: start included, end excluded. Active-during-window includes hazards already underway. Starts-during-window uses the archived effective start, not necessarily the bulletin issuance time. Precipitation-map timing ends at 12 UTC on the selected date. A truncated review window is labeled.

Storm polygons use archived polygon revision intervals. County/forecast-zone areas use the archive's resolved issue/expiration intervals, including resolved early endings; these are not a complete reconstruction of every message or historical boundary change. Source statuses may reflect later updates. No live warning status is implied. Map geometry is simplified by 150 meters for display; original archive files are retained locally.

Storm-polygon events are shown using those polygons instead of also drawing their county representations. Multiple zones/revisions of one event count once. Areas without geometry remain in the table. The source's carry-in query is limited to events starting within the preceding 30 days; older ongoing hazards are a coverage limitation. This view is for historical interpretation, not current warning decisions.

Sources: IEM NWS WWA archive. Original NWS text and source history are linked from each selected event.
